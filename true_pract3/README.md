# Учебная виртуальная машина (УВМ) - Ассемблер и Интерпретатор

Данный проект представляет собой реализацию ассемблера и интерпретатора 
для учебной виртуальной машины (Вариант №18). Проект выполнен на Python.

## Требования
* Python 3.9+

## Структура репозитория
```text
.
├── README.md           # Документация проекта
├── .gitignore          # Исключения для Git
├── Makefile            # Скрипт автоматизации сборки и запуска
├── src/                # Исходный код
│   ├── __init__.py
│   ├── assembler.py    # Этапы 1 и 2: Трансляция и генерация кода
│   ├── interpreter.py  # Этап 3: Интерпретатор и память
│   └── main.py         # CLI интерфейс
└── tests/              # Тестовые программы (JSON)
    ├── stage2_test.json
    └── copy_test.json
