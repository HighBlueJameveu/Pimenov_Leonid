Задача 6
Команды:

./checkComments codefor4task.c comment.c comment.py

Код checkComments файла:

#!/bin/bash

for file in "$@"; do

    case "$file" in
        *.c|*.js|*.py) ;;
        *) continue ;;
    esac

    first=$(head -n1 "$file")

    case "$file" in
        *.c|*.js)
            if [[ "$first" =~ ^[[:space:]]*(//|/\*) ]]; then
                echo "$file: Есть комментарий"
            else
                echo "$file: Нету комментария"
            fi
            ;;
        *.py)
            if [[ "$first" =~ ^[[:space:]]*# ]]; then
                echo "$file: Есть комментарий"
            else
                echo "$file: Нету комментария"
            fi
            ;;
    esac
done

Итог:

codefor4task.c: Нету комментария
comment.c: Есть комментарий
comment.py: Есть комментарий

Задача 8

Команды:

./packFiles folderFor8task .py
./packFiles folderFor8task .c
tar -tf archive.tar

Код packFiles файла:

#!/bin/bash

dir="${1:-.}"
ext="${2:-py}"

out="archive.tar"

case "$ext" in
    .*) ;;
    *) ext=".$ext" ;;
esac

find "$dir" -type f -name "*$ext" -print0 | tar --null -cf "$out" -T -

echo "$out"

Итог:

Создается файл archive.tar содержащий файлы одного введенного расширения
