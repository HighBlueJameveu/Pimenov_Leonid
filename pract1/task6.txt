Задача: 
Написать программу для проверки наличия комментария в первой строке файлов с расширением c, js и py.

Команды:

./checkComments codefor4task.c comment.c comment.py


Код checkComments файла:

#!/bin/bash

for file in "$@"; do

    case "$file" in
        *.c|*.js|*.py) ;;
        *) continue ;;
    esac

    first=$(head -n1 "$file")

    case "$file" in
        *.c|*.js)
            if [[ "$first" =~ ^[[:space:]]*(//|/\*) ]]; then
                echo "$file: Есть комментарий"
            else
                echo "$file: Нету комментария"
            fi
            ;;
        *.py)
            if [[ "$first" =~ ^[[:space:]]*# ]]; then
                echo "$file: Есть комментарий"
            else
                echo "$file: Нету комментария"
            fi
            ;;
    esac
done

Итог:

codefor4task.c: Нету комментария
comment.c: Есть комментарий
comment.py: Есть комментарий
