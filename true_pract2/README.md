# Вариант №18: Инструмент визуализации графа зависимостей

CLI-приложение на Python для анализа зависимостей пакетов Alpine Linux и построения транзитивного графа связей с последующей визуализацией в изображение.

## Реализованный функционал

### Этап 1. Минимальный прототип с конфигурацией
*   Чтение параметров из конфигурационного файла `config.toml`.
*   Вывод текущих настроек в формате ключ-значение.
*   Строгая валидация всех входных параметров.

### Этап 2. Сбор данных
*   Скачивание и распаковка архива индекса `APKINDEX.tar.gz` в оперативной памяти.
*   Парсинг формата Alpine Linux.
*   Извлечение списка прямых зависимостей для заданного пакета.

### Этап 3. Основные операции
*   Построение транзитивного графа зависимостей с помощью алгоритма.
*   Корректная обработка циклических зависимостей.
*   Визуализация графа с помощью библиотек `networkx` и `matplotlib` и сохранение в файл.
*   Поддержка тестового режима для локальных файлов.

## Структура проекта
*   `src/` — исходный код `main.py`, `apk_parser.py`, `graph_builder.py`.
*   `tests/` — unit-тесты для проверки валидации конфигурации.
*   `test_data/` — тестовые данные.
*   `config.toml` — конфигурационный файл.
*   `requirements.txt` — список зависимостей.
*   `run.sh` — bash-скрипт для быстрого запуска.
