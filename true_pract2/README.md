# Вариант №18: Визуализатор графа зависимостей пакетов (Этап 1)

Минимальное CLI-приложение на Python для настройки параметров анализа зависимостей пакетов Alpine Linux. На данном этапе приложение считывает TOML-конфигурацию, валидирует входные данные и выводит их в формате ключ-значение. 

## Структура проекта
* `src/` — исходный код приложения.
* `tests/` — unit-тесты для проверки валидации.
* `config.toml` — файл конфигурации.
* `run.sh` — скрипт для запуска.

## Как запустить
Выполните из корня проекта:
```bash
./run.sh
